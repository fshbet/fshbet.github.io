How these are measured

Every figure on this page is counted from source, not estimated.

Methodology

  • Tokens are counted with tiktoken cl100k_base across source, test, documentation and configuration files — the same encoding a language model would read them through.
  • Excluded from every count: dependencies, virtual environments, lockfiles, generated API schemas, minified bundles and build output. What remains is authored code.
  • Tests and documentation are reported separately from implementation, so each project's real ratio stays visible instead of being averaged away.
  • Each repository carries an INDEX.md written from its own source — architecture, usage, layout, and an explicit section naming what is missing.
