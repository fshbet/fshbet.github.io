How these are measured

Every figure on this page is counted from source, not estimated.

Methodology

  • Tokens are counted with tiktoken cl100k_base across source, test, documentation and configuration files — the same encoding a language model would read them through.
  • Excluded from every count: dependencies, virtual environments, lockfiles, generated API schemas, minified bundles and build output. What remains is authored code. For the CAD project that means the exported STL meshes are excluded — they are build output of the OpenSCAD source, which is what gets counted.
  • Tests and documentation are reported separately from implementation, so each project's real ratio stays visible instead of being averaged away.
  • Each software repository carries an INDEX.md written from its own source — architecture, usage, layout, and an explicit section naming what is missing. The CAD project carries docs/design-notes.md instead: the full measurement table, the coordinate transform, and the validation record.
  • One card reads differently. The enclosure has no test suite, so its third metric counts printed parts rather than tests. Everything else on this page is software.
